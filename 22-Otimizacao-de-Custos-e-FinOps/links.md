# Referencias Oficiais

## Essencial

- [AWS Cost Management User Guide](https://docs.aws.amazon.com/cost-management/latest/userguide/what-is-costmanagement.html) - Visao oficial de ferramentas de custo; prioridade para entender o conjunto.
- [AWS Cost Explorer](https://docs.aws.amazon.com/cost-management/latest/userguide/ce-what-is.html) - Analise historica e tendencias; importante para medir antes de otimizar.
- [AWS Budgets](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html) - Alertas e acompanhamento de limites; prioridade para governanca recorrente.
- [Cost and Usage Report](https://docs.aws.amazon.com/cur/latest/userguide/what-is-cur.html) - Base detalhada para alocacao e analise avancada.

## Aprofundamento

- [AWS Savings Plans](https://docs.aws.amazon.com/savingsplans/latest/userguide/what-is-savings-plans.html) - Essencial para commitment flexivel de compute.
- [Amazon EC2 Reserved Instances](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-reserved-instances.html) - Referencia para compromissos EC2 e trade-offs.
- [Amazon EC2 Spot Instances](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-spot-instances.html) - Importante para workloads tolerantes a interrupcao.
- [AWS Compute Optimizer](https://docs.aws.amazon.com/compute-optimizer/latest/ug/what-is.html) - Apoia rightsizing com recomendacoes.

## Referencia

- [Amazon S3 storage classes](https://docs.aws.amazon.com/AmazonS3/latest/userguide/storage-class-intro.html) - Use para lifecycle e custo de armazenamento.
- [AWS Data Transfer](https://aws.amazon.com/ec2/pricing/on-demand/#Data_Transfer) - Consulte para lembrar que arquitetura de rede/dados impacta custo.
- [AWS Organizations consolidated billing](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/consolidated-billing.html) - Relevante para contexto multi-account.
