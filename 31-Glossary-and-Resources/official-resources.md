# Glossary and Official Resources

## Glossary

- **7 Rs:** migration strategies: rehost, replatform, refactor/re-architect, retire, retain, relocate and repurchase.
- **Landing zone:** a multi-account foundation with governance, identity, networking and logging.
- **RTO:** maximum acceptable time to restore service.
- **RPO:** maximum acceptable data loss, expressed as time before the disruption.
- **Guardrail:** a governance control. AWS Control Tower controls can be preventive, detective or proactive.
