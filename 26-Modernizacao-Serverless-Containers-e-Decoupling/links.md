# Referencias Oficiais

## Essencial

- [AWS Lambda Developer Guide](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html) - Base para workloads event-driven e low-ops; use para validar limites e integrações.
- [Amazon ECS Developer Guide](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/Welcome.html) - Essencial para containers AWS-native e Fargate.
- [Amazon EKS User Guide](https://docs.aws.amazon.com/eks/latest/userguide/what-is-eks.html) - Referencia para decidir quando Kubernetes gerenciado e justificavel.
- [Amazon SQS Developer Guide](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/welcome.html) - Prioridade para filas, buffering, retry e DLQ.

## Aprofundamento

- [Amazon EventBridge User Guide](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-what-is.html) - Importante para roteamento de eventos entre dominios.
- [AWS Step Functions Developer Guide](https://docs.aws.amazon.com/step-functions/latest/dg/welcome.html) - Relevante para orquestracao de workflows e compensacao.
- [AWS Fargate](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/AWS_Fargate.html) - Use para comparar containers sem gerenciar instancias.

## Referencia

- [AWS Prescriptive Guidance - Strangler fig pattern](https://docs.aws.amazon.com/prescriptive-guidance/latest/cloud-design-patterns/strangler-fig.html) - Leitura chave para modernizacao incremental.
- [AWS Prescriptive Guidance - Migration strategy](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-strategy/welcome.html) - Ajuda a posicionar rehost, replatform e refactor.
- [Amazon SNS Developer Guide](https://docs.aws.amazon.com/sns/latest/dg/welcome.html) - Consulte para pub/sub quando multiplos assinantes precisam receber notificacoes.
