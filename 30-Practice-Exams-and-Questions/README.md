# Practice Exams and Questions

This module provides a sample of SAP-C02 preparation material. It supports scenario reading, elimination of alternatives and domain-based review; it does not replace a complete practice question bank.

## Main files

- [questions.md](./questions.md): 10 mixed questions.
- [domain-practice-exams.md](./domain-practice-exams.md): 12 questions, three per SAP-C02 domain.
- [error-log.md](./error-log.md): a short template for recording error patterns.
- [final-review-sap-c02.md](./final-review-sap-c02.md): a concise final-review plan.
