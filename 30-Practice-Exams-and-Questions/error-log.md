## Error classification

- **Reading:** overlooked an explicit constraint.
- **Trade-off:** chose a technically valid option that was less suitable for the scenario.
- **Scope:** treated an organizational problem as an isolated configuration issue.
- **Operations:** ignored automation, observability or ongoing governance.
- **Cost:** optimized a local price while increasing total cost.
