# Hands-On Labs

This module indexes the existing labs and workshops in the SAP-C02 learning path. The goal is to practice architectural decisions with controlled scope, low cost and explicit resource cleanup.

| Practical objective | Recommended lab |
|---|---|
| Transit Gateway and routing between VPCs | [05 - Advanced Networking](../05-Advanced-Networking-VPC-and-Transit-Gateway/lab.md) |
| Hybrid connectivity and DNS | [06 - Hybrid Connectivity](../06-Hybrid-Connectivity-Direct-Connect-VPN-and-DNS/lab.md) |
| Edge protection and inspection | [07 - PrivateLink and Network Security](../07-PrivateLink-Network-Firewall-WAF-and-Shield/lab.md) |
| Multi-AZ, multi-Region and failover | [09 - High Availability](../09-High-Availability-Multi-AZ-and-Multi-Region/lab.md) |
| Managed relational databases | [12 - RDS and Aurora](../12-RDS-Aurora-and-Relational-Database-Strategies/lab.md) |
| IaC, CI/CD and rollback | [17 - CloudFormation and CI/CD](../17-CloudFormation-CICD-and-Deployment-Strategies/lab.md) |
| Disaster recovery and backup | [20 - DR and Backup](../20-Disaster-Recovery-Backup-RTO-and-RPO/lab.md) |
| Migration and modernization | [23](../23-Migration-Hub-Discovery-and-the-7-Rs/lab.md), [24](../24-AWS-MGN-DMS-SCT-and-Workload-Migration/lab.md), [26](../26-Modernization-Serverless-Containers-and-Decoupling/lab.md) |

## Criteria before execution

- Estimate cost and execution time.
- Use a study or sandbox account.
- Document the rollback criteria.
- Remove resources when finished.
